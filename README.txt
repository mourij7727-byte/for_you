PAPU BIRTHDAY SURPRISE — MUMU & DUDU INSPIRED EDITION

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html directly in a browser, or use the Live Server extension.

WHAT'S INCLUDED
- Cute CSS-drawn panda couple on the opening screen (no extra image download required)
- Soft pink, cream, and lavender romantic theme
- Original personal letter and six-screen birthday journey
- Four memory photos in assets/photos
- Tamil love melody files in assets/music
- Interactive photo lightbox, floating hearts, birthday celebration, and replay button
- Responsive styling for mobile and desktop

NOTES
- The pandas are an original CSS illustration inspired by the general cute panda-couple aesthetic; they are not official Mumu & Dudu artwork.
- Music playback may require tapping the Play melody button because browsers block autoplay.
- Keep the assets folder beside index.html so the photos and music can load.
